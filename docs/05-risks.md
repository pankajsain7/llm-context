# F. Research Risks (ranked)

Status: 2026-10-20, aligned with pre-pilot design revision 3.2. Ranking combines likelihood and impact on validity; practical risks are ranked by their potential to block completion. Methodology remains proposed until Prof. Höll approves it. Evidence labels: **[V]** verified, **[P]** full text, **[A]** abstract, **[BK]** background knowledge, **[I]** interpretation, **[NV]** not verified.

## Early-warning indicators (checked at Gates 2 and 3)

| Indicator | Threshold that triggers action | Action |
|---|---|---|
| Reconstruction failures | >2% of validation sample | Investigate mapping; any dataset replacement requires a separate approved decision |
| Invalid or unparseable outputs | > 2% | Tighten the output constraint or parsing on the validation split |
| Valid two-candidate scores (M1) | Unavailable or <98% in any core condition | Obtain D13 approval for binary IPW-MCC before test inference; log answer and score failures separately |
| Context blocks not `ok` (`line_limit`, `short`, `no_hits`) | Frequent in Gate 2 checks | Bound windows by tokens, revisit B (D9), and report the rates |
| C0 vs repeated-C0 flip rate | Comparable to the C0 vs C2 flip rate | Re-run the power analysis; consider more instances or a more deterministic model |
| Blinded relevance audit | Both raters do not favour C2 in mean paired rating | Review implementation; narrow semantic claims or obtain a documented protocol revision. Proxy significance is not a gate |
| Eligible positive yield/precision | Insufficient for intended conclusion | Review attainable precision and bounded claims with Prof. Höll; no automatic cap/dataset change |
| Pilot predictive signal | Near chance, if a score metric is available | Check implementation/scoring validity, retain null results; do not search models/prompts for a positive context effect. Binary access has no ROC-AUC gate |
| Project-aware uncertainty | Pilot intervals too wide to support the intended conclusion | Discuss attainable precision/claim scope; do not enlarge the practical margin merely to obtain equivalence |
| Label-recall probe | Clearly above chance | Prefer a model with an earlier cutoff for M1, and report the probe result with every model |
| Projected cost | > agreed budget | Shrink the C3 seed count, the RQ3 series (subsample), and the M3 sample, in that order |
